# Taivutin

Taivutin on suomen kielen sanoja taivuttava salasanageneraattori.

## Käyttö

`python taivutin.py [sanojen määrä] [-w sanalista]`

Sanalistat:

- `kotuskarsittu` (oletus): Kotuksen nykysuomen sanalista (2006) ilman yhdyssanoja, joille listassa ei ole taivutustietoja. Sama sanalista kuin [Voikkogenissa](https://github.com/indigane/voikkogen).
- `kotusfull`: Kotuksen nykysuomen sanalista 2024 kokonaisuudessaan; yhdyssanat taivutetaan viimeisen osansa mukaan.
- `wikisanakirja`: englanninkielisen Wikisanakirjan suomenkieliset sanat taivutuksineen.

Selaimessa toimiva versio on haarassa [web](https://github.com/indigane/taivutin/tree/web) ja julkaistuna osoitteessa [indigane.github.io/taivutin](https://indigane.github.io/taivutin/).

## Lisenssit

### Wikisanakirja

Sanalista on koottu englanninkielisen Wikisanakirjan (en.wiktionary.org) suomenkielisistä sanoista ja niiden taivutuksista.
